Human intent. AI judgment. Precise tools.

Three distinct roles—not an AI given unrestricted control of your asset.
01 / THE HUMAN

Decides what matters.

Describes the intended asset
Chooses destination and use
Reviews proposed changes
Approves, declines or refines

02 / THE AI AGENT

Connects intent to action.

Reads measurements + images
Identifies meaningful parts
Chooses supported operations
Reviews fresh visual evidence

03 / THE TOOLS

Execute and check.

Validate typed arguments
Apply authorized GLB edits
Reopen and measure results
Export model + diagnostics

One shared repair engine: available through the CLI and called by the agent as typed tools.
The agent proposes. Approval stays with you.Original preserved · limitations reported
