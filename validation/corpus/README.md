# Real-world corpus

Each asset follows the immutable-raw layout in
[`docs/REAL_WORLD_VALIDATION_PLAN.md`](../../docs/REAL_WORLD_VALIDATION_PLAN.md). Text records,
prompts, manifests, adjudication, and reports are designed to be committed. Large source, derived,
Unreal, and screenshot binaries are ignored until public-use rights and repository-size handling are
confirmed.

Never edit a file below an asset's `raw/` directory. Register its SHA-256 before blind evaluation,
and derive every mutation or human reference from a copy.
