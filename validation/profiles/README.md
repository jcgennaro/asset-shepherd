# Validation profiles

The initial untouched Patchling measurement showed that the existing 1.8 m robot profile conflicts
with the addendum's general 0.9–1.5 m compact-mascot target. `small_stylized_static_mesh.json`
therefore expresses that approved range as a 1.2 m target with ±0.3 m tolerance. It does not dispatch
on Patchling or another corpus asset ID. Do not tune profiles after manual DCC diagnosis.
